Gemini API 키 설정

이 앱은 선생님 본인의 무료 Gemini API 키로 동작합니다. 처음 한 번만 설정하면 됩니다.

  1. Google AI Studio에 개인 Google 계정으로 로그인합니다.
  2. Create API key(API 키 만들기)를 눌러 키를 만듭니다. 결제 정보는 등록하지 마세요(무료 등급 유지).
  3. 만들어진 키를 복사해 아래 칸에 붙여 넣고 ‘연결 확인’을 누릅니다.

무료 등급에서는 Google이 입력·출력 내용을 서비스 개선에 활용할 수 있고 사람이 검토할 수도 있습니다. 학생 개인정보는 절대 입력하지 마세요.
